# ScolioVision · 曲度智衡

## 脊柱侧弯影像分析与康复交互科研系统

ScolioVision（曲度智衡）是一套面向脊柱侧弯影像分析场景构建的科研型软件系统。项目围绕影像输入、图像预处理、推理服务、结构化结果展示、分析历史和康复内容交互形成完整工作流，为脊柱侧弯自动评估及相关计算机视觉研究提供统一的软件基础。

系统采用模块化设计，图像处理、推理服务、结果数据结构、前端交互和康复内容均保持相对独立，可灵活接入关键点检测、终板检测、图像分割、角度估计及其他深度学习模型。

## 核心能力

- 脊柱影像上传与本地预处理；
- 图像格式、大小和有效性校验；
- 统一推理服务适配层；
- Cobb 角、侧弯类型等结构化结果展示；
- 推理来源、输入指纹与结果区间管理；
- 分析历史记录与本地存储；
- 康复动作库与视频交互；
- 移动端和桌面端响应式布局；
- Python / PyTorch / ONNX / Flask / FastAPI 模型服务接入；
- 面向科研实验的接口契约与研究协议文档。

## 系统流程

```text
影像输入 → 本地校验与预处理 → 推理服务 → 结构化分析结果 → 结果展示 / 历史管理 / 康复内容交互
```

## 运行方式

```bash
cd Scoliosis/src
npm install
npm run dev
```

生产构建：`npm run build`  
项目检查：`npm run check`

## 科研方向

项目可进一步扩展至椎体关键点定位、终板检测、上下端椎识别、Cobb 角自动测量、侧弯模式分类、影像质量控制、外部验证和纵向随访分析等研究方向。

在 Cobb 角估计任务中，可采用 MAE、RMSE、误差阈值内比例、ICC 和 Bland–Altman 分析等指标；分类任务可使用 Precision、Recall、F1-score、混淆矩阵及概率校准指标。
